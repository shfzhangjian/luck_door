# 门窗云设计

中国门窗可视化设计平台的第一阶段原型。

## 当前定位

本项目不直接魔改 Open Frame Studio 原仓库，而是另起一个 Web 项目，把 OFS 作为技术参考和可移植能力来源。

第一阶段目标是打通：

```text
门窗绘制
  -> 可视化 JSON
  -> 算料引擎
  -> BOM / 下料明细
  -> 后续 MES / ERP / WMS / 设备适配接口
```

## 为什么不直接改 OFS

Open Frame Studio 的优势是门窗 2D/3D、型材、生产清单、导出和几何计算已经有基础，但它的完整能力仍围绕 Tauri 桌面应用。

OFS Web 模式通过 WASM 和浏览器 fallback 支持一部分功能，但文件导入导出、IFC、DXF、PDF、XLSX、CNC、采购、计划等能力与桌面端不完全一致。直接把它改成中国门窗 SaaS 平台，会继承桌面架构和荷兰业务模型，后期维护成本高。

本项目采用：

```text
Open Frame Studio = 技术参考 / 算法参考 / 原型验证
门窗云设计 = 中国门窗 Web 平台主线
```

## 第一版已包含

- 项目、订单、批次、客户、窗号、楼层、房间等中国业务字段
- 门窗尺寸、数量、外形、分格和单元类型配置
- 二维出图：开启状态、型材颜色、整窗/分格/执手标尺、台高和室内外俯视投影
- 固定玻璃、平开扇、内开内倒、上悬、下悬、普通推拉、提升推拉、PSK平移内倒、平行推拉、平行推出、入墙推拉、转角推拉、上下提拉、折叠、门扇、纱窗、百叶、格条、面板、留空
- 门店式快速绘图工具：素材盘、选中单元快速替换、竖向/横向等分、均分尺寸、双扇平开快捷套用
- 按门窗设计业务重组的工具库：框、梃与分格、开启扇、推拉与折叠、格条与辅件，并支持工具搜索
- 局部竖梃和局部横梃：可指定位置、起止范围、型材、端接/贯通节点，支持二维选择、右键菜单、3D同步、玻璃分区校验和BOM追溯
- 项目级拼接料和转角料：支持标准/加强拼接、默认/弧形面/万能/矩形转角、正反装、60-180度角度、两翼宽度、局部跨度、相邻框处理和无柱模式
- 拼接/转角节点支持二维标记与右键编辑、节点详图、3D姿态，以及型材、连接件、密封和紧固件BOM；由宿主窗唯一归属，避免多窗重复计料
- 多窗组合设计：以根窗建立装配坐标系，支持左、右、上、下停靠与自由毫米坐标定位，可设置参照窗、对齐、间隙、错位量、旋转角和工程连接节点
- 组合模式共用同一套2D/3D布局结果，输出组合窗号、关联关系、总体宽高深，并支持在画布中选择成员、右键编辑或进入组合3D预览
- 组合BOM保留每樘窗独立生产尺寸，同时输出项目级组合清单和可追溯的MBOM行，拼接/转角节点只计算一次
- 安装与包套首版：支持内外双包、单侧包套和洞口衬板，支持四边、三边无底、左上、右上及自定义应用边
- 安装基准区分洞口内安装与外墙外挂安装；洞口内可选墙厚居中、外口齐平、内口齐平和自定义框位，统一规定框位正值向室内、负值向室外
- 包套参数包含墙厚、框位偏移、内外包边宽度、板厚、材料和颜色，并同步进入二维轮廓、安装截面、3D墙洞及BOM
- 3D使用完成地面、墙洞口、固定外框、轨道和活动扇的安装层级；窗台高度决定洞口标高，地面不再跟随模型最低点漂移
- 末端转角推拉模块将展开宽度折成真实L形：3D墙体、外框和双翼轨道共用转角节点，二维室内/室外俯视图同步显示墙线、轨道和开启方向
- 按需加载的独立 3D 窗体预览：基于 Three.js 生成框、扇、玻璃、五金和安装洞口
- 组合开启配置：双平开主从扇/假中梃、多轨推拉、提升推拉、PSK、平行推拉/推出、单/双向入墙、60-180度带柱/无柱转角推拉、单/双动上下提拉、2-12扇折叠、通行扇和一体纱窗
- 3D 构件开合：每个活动扇可单选或多选、拖动开启幅度，并按主扇到从扇的顺序开启、反序关闭；支持平开/外开、内倒、悬窗、普通/提升/平行/入墙/转角推拉、PSK两种动作、平行推出、上下提拉、折叠和门扇动画
- 开启方向使用稳定JSON编码；`openingAssembly` 保存扇数、轨道、主从顺序、收拢方向和纱窗配置，设计JSON、EBOM、MBOM和制造接口包保持同一语义
- 产品材料配置：系列、框料、扇料、中梃、拼接料、转角料、压条、胶条、玻璃、五金
- 自定义材料包
- 内置窗型组件和自定义窗型组件
- `cn-door-window-design.v2` 设计 JSON 导入导出；旧版数据导入时自动补充稳定窗格ID和拓扑结构
- 设计JSON将台高、执手高度等制造/安装参数与不参与BOM的 `viewOptions` 显示设置分离
- 算料状态：设计中、已算料、已确认、已冻结、已变更
- 独立算料/BOM工作页，集中显示汇总、制造明细以及确认和冻结操作
- 设计 JSON、BOM JSON、Manufacturing Package JSON 导出

| WMS 入库发货 | 仅预留接口 | 后续接库存和发货控制 |

## 文件

- `dist/index.html`：当前可运行页面骨架
- `dist/assets/app.css`：工作台样式
- `dist/assets/app.js`：设计、算料、BOM和接口包逻辑
- `docs/door-window-design.v1.schema.json`：第一版规则网格设计 JSON 结构
- `docs/door-window-design.v2.schema.json`：兼容规则网格并支持框段、区域、局部中梃、项目级拼接/转角节点及多窗组合定位的设计 JSON 结构
- `docs/drawing-product-function-plan.md`：绘图工具、包套、转角节点和多窗组合的产品规划
- `docs/manufacturing-package.v1.md`：后续 MES / ERP / WMS / 设备适配接口包说明
- `docs/opening-combinations-roadmap.md`：已实现组合和后续开合方式计划
- `docs/domain-knowledge-foundation.md`：墙体、洞口、安装、门窗结构、材料、性能、尺寸链、BOM与标准规则的领域知识底座

## 下一步建议

1. 完善包套规则校验：无底框/门槛冲突、包边尺寸适配、企业截面库和节点做法版本。
2. 增强多窗装配校验：重叠、悬空连接、节点角度一致性、运输拆分和组合数量规则。
3. 增强拖拽绘图：支持素材拖入、连续中梃、局部尺寸编辑和吸附。
4. 扩展3D：加入型材截面、材质贴图、锁点联动、碰撞限制和室内/外视角。
5. 将 `dist/index.html` 拆成正式前端工程模块，并把算料函数独立成 `calculation-engine`。
6. 增加运行时 JSON Schema 校验，把组件库、产品库、玻璃库、五金库拆成可导入数据。
7. 接入后端项目保存、冻结BOM版本及MES/ERP/WMS接口。
