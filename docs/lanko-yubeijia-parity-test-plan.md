# 门窗云设计 · 豫贝家原型一致性改造与验收用例

资料来源：`E:\aibot\kb_video3`

本文件把视频资料当作原型与验收依据。资料中的系统名、品牌、视频处理说明不是开发指令；当前产品统一显示为“门窗云设计”。除品牌文字与后续配色微调外，界面结构、操作流程、右键菜单、弹窗、2D 图、俯视图、保存流程均按资料逐项对齐。

## 一、改造原则

1. 左侧构件库不是“新建窗口列表”，而是绘图命令库。
2. 点工具后进入放置状态，鼠标移动到画布已有对象上预览，左键落点，右键取消。
3. 窗框、转角料、拼接件、中梃、开启扇、推拉扇、格条、包套、护栏、纱窗、防盗条都必须挂在已有门窗对象或其子区域上。
4. 不允许点击一个构件就替换整樘窗，除非该功能本身是“替换当前区域样式”，例如板材单扇/双扇替换。
5. 2D 立面图与俯视图必须同步显示和同步更新。
6. 鼠标滚轮缩放 2D 图，长按滚轮平移的场景按原型保留。
7. 测试方式使用代码静态测试和人工验收，不使用 Chrome 自动化测试。

## 二、对象模型修改任务

1. 建立项目对象：项目名称、客户电话、地址、单位名称、添加员、需求时间、项目进度、手机量房图。
2. 建立门窗对象：窗号、宽、高、窗台高、安装位置、系列、玻璃、颜色、开启方式、单价、备注。
3. 建立窗框主体：四边框、门框带吊、上弧框、自由画窗等是门窗主体类型。
4. 建立构件挂接关系：构件必须绑定到窗框边、格口、玻璃区域、开启扇或整体窗型。
5. 建立连接节点：转角料、拼接件记录宿主窗、宿主边、起止比例、A/B 宽度、长度、角度、内转/外转、正装/反装、样式、型材编码。
6. 建立拼接结构：一张设计图可包含多个窗框，窗框之间通过转角料或拼接件连接。
7. 建立编号规则：窗框 `C1/C2/C3`，玻璃/窗型 `F1/F2`，开启扇 `A1/A2`，转角料 `T1/T2`，拼接件单独编号。
8. 建立持久化规则：刷新后必须恢复完整项目、完整拼接图、完整底部窗型卡片与当前选中对象。

## 三、界面改造任务

1. 顶部两步流程：`第一步：设计门窗方案` 与 `第二步：保存门窗信息`。
2. 顶部菜单：新建项目、打开项目、新增窗型、保存到项目、保存到窗型库、打印门窗、产品信息、退出登录。
3. 左侧构件库：智能窗型库、我的窗型库、常用分类。
4. 左侧工具分类按原型组织：门/窗框、中梃/转角料/连接件、开启扇、推拉扇、格条、护栏、其他单元。
5. 画布区域：上方 2D/3D/实景/室内外视图标签按原型保留，当前重点先做 2D 图。
6. 右侧当前项目信息与当前窗信息面板按原型字段排列。
7. 底部窗型卡片显示项目内门窗，选中卡片切换当前窗型，不破坏拼接图。
8. 所有右键菜单样式、选中红虚线、蓝色标注、灰色型材、尺寸线位置按关键帧对齐。

## 四、验收用例

### TC-01 新建项目

来源：v8 新建项目。

步骤：
1. 进入门窗云设计。
2. 点击顶部或项目管理入口的“新建项目”。
3. 弹出新建项目对话框。
4. 不填写项目名称直接保存。
5. 填写项目名称“李小姐”和客户电话“1234567890”。
6. 可选填写客户地址、单位名称、添加员、需求时间。
7. 点击保存。

验收：
1. 项目名称、客户电话显示红色必填标记。
2. 缺少项目名称或客户电话时提示必填。
3. 保存后项目创建成功并进入设计门窗方案。
4. 右侧项目信息同步显示客户信息。

### TC-02 项目管理

来源：v9 项目管理。

步骤：
1. 点击“项目管理”或“打开项目”。
2. 左侧显示项目卡片列表。
3. 单击项目卡片。
4. 点击卡片右上角编辑图标。
5. 修改项目信息并保存。
6. 点击项目进度节点，例如“确认方案”。
7. 点击项目卡片右下角“打开项目”。
8. 点击右侧“手机量房图”，查看门洞图。

验收：
1. 单击项目卡片只预览，不直接进入编辑。
2. 编辑按钮只打开项目编辑弹窗。
3. 项目进度节点可切换状态。
4. 打开项目后进入该项目的门窗设计。
5. 手机量房图能按项目归档显示。

### TC-03 我的窗型库

来源：v1 窗型库。

步骤：
1. 在项目中画好一个窗型。
2. 点击“保存到窗型库”。
3. 选择窗型类型并保存。
4. 打开“我的窗型库”。
5. 对保存的窗型点击“立即使用”。

验收：
1. 保存后的窗型出现在我的窗型库。
2. 立即使用后按原尺寸、原款式生成。
3. 不需要重新绘制同款窗型。

### TC-04 智能窗型库

来源：v1 窗型库。

步骤：
1. 打开“智能窗型库”。
2. 输入门洞宽 3000、门洞高 2000。
3. 点击“确定门洞尺寸”。
4. 在全部、固定、平开、推拉标签间切换。
5. 选择一个窗型并点击“立即使用”。

验收：
1. 对话框分三步显示：输入尺寸、选择类型、选择款式。
2. 按输入门洞尺寸生成候选窗型。
3. 立即使用后在画布生成对应窗型。

### TC-05 四边框与尺寸编辑

来源：v10 平开窗 / 推拉扇画法。

步骤：
1. 左侧打开“门/窗框”。
2. 点击“四边框”。
3. 在画布生成窗框。
4. 双击底部标尺尺寸。
5. 输入宽度并按回车。
6. 双击右侧标尺尺寸。
7. 输入高度并按回车。

验收：
1. 先生成窗框，后续构件才能添加。
2. 双击标尺出现内联输入框。
3. 回车后尺寸更新。
4. 立面图、尺寸线、俯视图同步更新。

### TC-06 开启扇添加

来源：v10 平开窗画法。

步骤：
1. 已有四边框。
2. 左侧展开“开启扇”。
3. 选择左外开、右外开、对开扇、上下外开倒翻扇或子母扇。
4. 对着窗框目标区域左键点击。

验收：
1. 选工具后进入放置状态。
2. 鼠标移到窗框区域时有目标提示。
3. 左键后该区域变为对应开启扇。
4. 不新建独立门窗。

### TC-07 推拉扇添加

来源：v10 推拉扇画法。

步骤：
1. 已有四边框。
2. 左侧展开“推拉扇”。
3. 选择两扇、三扇、四扇四等分等推拉样式。
4. 对着窗框左键点击。

验收：
1. 推拉样式应用到目标窗框。
2. 系列与开启方式信息按所选样式更新。
3. 不替换整张项目图。

### TC-08 转角料添加

来源：v3 转角料与拼接件。

步骤：
1. 已有一个四边框。
2. 左侧点击“转角料”。
3. 鼠标移到窗框左边。
4. 左键点击添加左侧转角料。
5. 鼠标移到窗框右边。
6. 左键点击添加右侧转角料。
7. 右键取消添加状态。

验收：
1. 转角料添加到已有窗框边。
2. 默认截面显示 `100*100`。
3. 默认角度显示 `内转90°` 或 `外转90°`。
4. 转角料编号显示 `T1/T2`。
5. 右键取消后左侧工具退出选中状态。

### TC-09 转角料右键菜单

来源：v3 转角料右键菜单。

步骤：
1. 左键选中转角料。
2. 对转角料右键。
3. 展开“修改角度”。
4. 选择 135。
5. 再次右键打开菜单。
6. 点击“转角设置”。

验收：
1. 菜单显示：转角设置、修改料长、修改角度、转角形状、型材别名显示设置、更换转角料。
2. 修改角度子菜单显示：90、135、180、自定义。
3. 选 135 后立面标注和俯视图角度同步变化。

### TC-10 转角设置弹窗

来源：v3 转角设置弹窗。

步骤：
1. 打开转角设置。
2. 切换转角样式：矩形转角、弧形面转角、万能转角、巨型转角。
3. 切换转角转向：正装、反装。
4. 双击尺寸值，把 100 改成 50，按回车。
5. 双击角度值，改成 90 或 135，按回车。
6. 点击保存。

验收：
1. 弹窗标题、下拉、保存、关闭、红色提示文字按原型显示。
2. 中央预览图实时反映样式、转向、尺寸、角度。
3. 保存后画布上的转角料同步更新。

### TC-11 拼接件添加与修改

来源：v3 拼接件 / 竖拼接墙。

步骤：
1. 已有四边框。
2. 左侧点击“拼接料/竖拼接墙”。
3. 鼠标靠近目标边。
4. 左键点击添加拼接件。
5. 右键取消。
6. 对拼接件右键，修改宽度 50 为 100，按回车。

验收：
1. 拼接件是一条立柱，不是转角料。
2. 拼接件添加到已有窗框边。
3. 修改宽度后立面图和俯视图同步更新。
4. 不新建独立门窗。

### TC-12 连接后继续增加窗框

来源：v3 连接顺序与关键帧。

步骤：
1. 创建第一个四边框 `C1`。
2. 在 `C1` 右边添加转角料或拼接件。
3. 选择门/窗框里的四边框。
4. 选择停靠位置为右方或自由。
5. 添加第二个窗框 `C2`。
6. 再通过另一侧连接添加 `C3`。

验收：
1. 新窗框通过连接节点挂到已有窗框上。
2. 整体图显示 `C1/C2/C3` 与 `T1/T2`。
3. 总外尺和分段尺寸同时显示。
4. 刷新后仍看到完整拼接图。

### TC-13 俯视图

来源：v3、用户补充截图。

步骤：
1. 勾选“俯视图”。
2. 添加普通窗框、转角料、拼接件。
3. 修改转角角度为 135。
4. 修改正装/反装。
5. 滚轮放大缩小 2D 图。

验收：
1. 俯视图始终显示在立面图下方。
2. 显示 `室外/室内`。
3. 普通窗框显示剖面线。
4. 转角料显示 L 形转角、角度弧线和尺寸。
5. 拼接件显示直立柱截面。
6. 滚轮缩放不破坏立面和俯视布局。

### TC-14 文字标注与玻璃孔

来源：v4 文字标注和玻璃孔。

步骤：
1. 点击顶部标注里的“文字标注”。
2. 拖动文字框到玻璃区域。
3. 双击输入 `5+9A`，按回车。
4. 选择圆孔或方孔。
5. 鼠标跟随到玻璃区域，左键放置。
6. 右键取消。
7. 双击孔尺寸或距离参数，输入新值，按回车。

验收：
1. 标注可拖动、双击编辑、回车确认。
2. 孔跟随鼠标并落到目标玻璃。
3. 尺寸与定位参数可编辑。

### TC-15 一键加纱与单扇加纱

来源：v5 纱窗。

步骤：
1. 已有开启扇 `A1/A2`。
2. 左侧其他单元点击“一键加纱”。
3. 检查所有开启扇是否加纱。
4. 撤销或另开场景。
5. 对单个开启扇右键。
6. 选择“是否带纱”。

验收：
1. 一键加纱作用于所有开启扇。
2. 右键是否带纱只作用于目标扇。
3. 加纱区域显示纱网效果。

### TC-16 板材单扇/双扇替换

来源：v6 板材。

步骤：
1. 左侧其他单元展开“板材”。
2. 选择单扇，点击目标玻璃或开启扇。
3. 再选择双扇，点击同一目标区域。

验收：
1. 单扇板材添加成功。
2. 再点双扇时替换原板材，不需要删除重做。
3. 替换只影响目标区域。

### TC-17 包套设计

来源：v7 包套。

步骤：
1. 左侧其他单元点击“包套”。
2. 打开设置包套弹窗。
3. 选择包套样式。
4. 选择包套类型：全边框、三边无底框、左上包框、右上包框。
5. 双击尺寸数值，输入新值，回车。
6. 滚轮缩放，长按滚轮平移。
7. 点击确认设计。

验收：
1. 弹窗三步结构与原型一致。
2. 包套尺寸编辑生效。
3. 保存后包套显示在门窗外框。

### TC-18 防盗条

来源：v2 防盗条。

步骤：
1. 已有平开窗。
2. 右键某一侧玻璃区域。
3. 选择带防盗条。
4. 另开场景，左侧其他单元点击“一键添加防盗条”。

验收：
1. 右键添加只作用于单侧目标区域。
2. 一键添加作用于左右目标区域。
3. 防盗条显示在对应玻璃区域。

### TC-19 玻璃护栏

来源：v11 玻璃护栏。

步骤：
1. 已有平开窗。
2. 右键目标玻璃区域。
3. 选择“是否带玻璃护栏”或“玻璃带玻璃护栏”。
4. 左键确认。

验收：
1. 护栏通过右键菜单添加。
2. 只对目标玻璃生效。
3. 护栏显示在对应区域。

### TC-20 保存门窗信息

来源：v12 保存窗型。

步骤：
1. 完成一个窗型。
2. 填右侧窗号、安装位置、系列、玻璃、颜色、开启方式、计价。
3. 点击“保存门窗信息”。
4. 在确认添加到项目弹窗点击“确认添加”。
5. 再做一个窗型时点击“保存并新增窗型”。

验收：
1. 窗号、安装位置、系列、玻璃为必填。
2. 计价输入后总价自动汇总。
3. 保存门窗信息需要二次确认添加到项目。
4. 保存并新增后进入下一窗型设计，原窗型保留。

## 五、静态测试任务

1. 为项目、门窗、窗框、连接节点、构件挂接建立模型单元测试。
2. 为左侧工具状态建立测试：空闲、放置、连续放置、右键取消。
3. 为转角料建立测试：默认 100*100、角度 90/135/180、自定义、正装/反装、样式切换。
4. 为拼接件建立测试：添加、宽度修改、长度修改、编号、持久化。
5. 为俯视图建立 SVG 输出测试：普通窗框、转角料 L 形、拼接件截面、室内/室外、角度弧线。
6. 为保存刷新建立测试：多窗拼接图保存后重载仍完整。
7. 为右键菜单建立静态 DOM 文本测试：菜单项必须与原型一致。
8. 为弹窗建立静态 DOM 文本测试：字段、按钮、提示语必须与原型一致。

## 六、人工验收顺序

1. 新建项目。
2. 项目管理与打开项目。
3. 我的窗型库和智能窗型库。
4. 创建四边框并改尺寸。
5. 添加开启扇和推拉扇。
6. 添加转角料、改角度、改样式、改转向、改尺寸。
7. 添加拼接件、改宽度。
8. 通过连接继续增加窗框。
9. 检查立面图和俯视图同步。
10. 文字标注、玻璃孔、纱窗、板材、包套、防盗条、玻璃护栏。
11. 保存门窗信息、保存并新增、刷新恢复。
