# 开合组合实施路线

本文区分“已经进入设计 JSON、二维图、三维动作和 BOM 的能力”与“后期产品计划”。组合参数统一保存在 `cell.openingAssembly`。

## 当前已实现

| 系列 | 当前组合 | 设计与输出 |
| --- | --- | --- |
| 平开窗/门 | 单扇、双扇；1或2个活动扇；左/右主扇；固定中梃、假中梃；内开、外开 | 主从扇独立构件、顺序开合、扇料/玻璃/执手/合页/假中梃 BOM |
| 内开内倒 | 单扇、双扇；平开优先、内倒优先；内倒/微通风/夜间通风档位 | 三维平开与内倒动作、配置进入 JSON/EBOM |
| 普通推拉 | 2-6扇、1-5活动扇、2-4轨、左收/右收/双向收 | 活动扇独立选择与推拉，按扇数/轨数输出玻璃、扇料、滑轮与轨道 |
| 提升推拉 | 2-4扇、1-3活动扇、2-3轨、左收/右收/双向收 | 先提升后平移的三维动作，按活动扇输出执手/滑轮 |
| PSK平移内倒 | 2-4扇、1-2活动扇、内倒优先/平移优先、左/右平移 | 三维可切换内倒与“脱离密封面后平移”，输出专用滑车、剪刀撑、轨道和执手 |
| 平行推拉 | 2-4扇、1-2活动扇、左/右收拢 | 三维先整扇平行脱离再滑移，输出专用平行滑车和轨道 |
| 平行推出 | 单扇四边同步外推 | 二维/俯视表达等距外移；三维固定框留在墙洞，四点定长滑撑连接活动扇并随行程改变角度，输出同步剪刀撑和执手 |
| 入墙推拉 | 1-6扇、单侧/双侧入墙、1-3轨、可配置墙腔深度 | 二维和三维显示墙腔，输出隐藏轨道、盒体、缓冲器及检修组件 |
| 转角推拉 | 2-8扇、单侧/双侧开启、1-3轨、60-180度、带柱/无柱 | 三维生成两条空间扇组，输出双翼轨道、转角柱或无柱闭合密封件 |
| 上下提拉 | 两扇、单动或双动、上提/下拉/上下双动 | 两个活动扇可独立开合，输出双轨和配套平衡器数量 |
| 折叠门窗 | 2-12扇、左收/右收/双向收、内折/外折、左/右通行扇 | 折叠组独立选择与顺序开合，扇数驱动玻璃、扇料、承重轨和折叠五金 BOM |
| 配套纱窗 | 固定、平开、推拉、卷轴 | 二维标识、三维独立构件、活动纱扇开合和独立 BOM |
| 上悬/下悬 | 内开或外开单扇 | 二维开启图、三维绕横轴动作及五金 BOM |

## 后期优先级 P1

| 组合 | 需要补充的核心能力 |
| --- | --- |
| 折叠通行扇深化 | 通行扇先开、其余扇后折；奇偶扇规则、承重方向和五金约束 |
| 纱窗深化 | 金刚网、折叠纱、内置纱、可拆洗结构及与玻璃扇的互锁 |
| 高级推拉工程校核 | PSK/平行/入墙/转角推拉的尺寸上限、净开口、五金承重、锁点互锁和碰撞检查 |

## 后期优先级 P2

| 组合 | 需要补充的核心能力 |
| --- | --- |
| 中悬/立转窗 | 中轴或竖轴旋转、限位角度和重心校核 |
| 多点电动上悬/排烟窗 | 推杆数量、同步控制、开启角和消防接口字段 |
| 电动提拉/配重提拉 | 驱动器、配重、行程限位和防坠规则 |
| 门联窗与母子门 | 门槛、门扇/固定亮窗组合、主副门扇顺序和锁闭关系 |
| 多扇联动推拉 | 皮带/联动件、逐扇带动距离、极限位置和防夹碰撞 |

## 每种新组合的完成标准

1. JSON Schema 有稳定编码、参数范围和旧数据默认值。
2. 二维图表达扇数、方向、主从扇、尺寸和室内外关系。
3. 三维中每个活动构件可选中，并按真实运动顺序播放。
4. 算料规则覆盖型材、玻璃、五金、轨道、纱窗和特殊连接件。
5. 规则检查能阻止超尺寸、错误轨数、错误奇偶扇和构件碰撞。
6. EBOM、MBOM 与制造接口包保留相同的组合语义。
