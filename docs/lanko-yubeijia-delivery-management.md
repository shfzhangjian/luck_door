## 三、阶段性交付门槛

### 阶段 A：项目与原型框架

包含模块：M0、M1、M2。

专家验收重点：
1. 是不是像原型的云设计系统。
2. 项目管理流程是否符合门窗业务。
3. 窗型库是否能减少重复绘制。

### 阶段 B：核心绘图

包含模块：M3、M4、M5、M6。

专家验收重点：
1. 画图顺序是否正确。
2. 连接件是否挂在已有窗框上。
3. 转角料和拼接件是否能继续接出下一樘窗。
4. 俯视图是否表达真实空间关系。

### 阶段 C：辅件与安装

包含模块：M7、M8。

专家验收重点：
1. 附件是否按区域开关。
2. 包套是否符合门窗安装表达。
3. 玻璃孔、标注是否可编辑。

### 阶段 D：保存与业务闭环

包含模块：M9。

专家验收重点：
1. 门窗信息是否完整。
2. 保存并新增流程是否符合门店录单习惯。
3. 数据刷新后是否完整恢复。

## 四、执行规则

1. 每个模块先实现最小闭环，再补视觉细节。
2. 每次改动必须跑静态测试。
3. 优先使用代码静态测试和人工测试；完成一个可验收阶段后，可使用 Chrome 或可用浏览器截图辅助对照原型。
4. 如果当前环境无法调用 Chrome，必须记录为可用浏览器人工核对，不能写成 Chrome 验收。
5. 行业专家只验业务与操作是否符合原型，不看代码。
6. 未通过验收的模块进入返工队列，不进入下一阶段总验收。
